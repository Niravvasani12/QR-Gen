🔥 QR Code Generator

🌐 Live Demo: https://qr-gen-flame-eight.vercel.app

📂 Repository: https://github.com/Niravvasani12/QR-Gen

A modern, fast, and responsive QR Code Generator built with React + Tailwind CSS. Instantly generate high-quality QR codes for text, URLs, Wi-Fi credentials, or custom data.

✨ Features

⚡ Real-time QR code generation (Debounced Input)

🌙 Dark / Light mode with system preference detection

📥 Download QR as high-quality JPG (512×512)

📱 Native mobile sharing (Web Share API)

🔒 Input sanitization for security

🎨 Smooth animations using Framer Motion

📱 Fully responsive design

🚀 Lazy-loaded components for better performance

🛠️ Tech Stack

React 18

Tailwind CSS

Framer Motion

react-qr-code

Lucide React Icons

Web3Forms (Contact Form)

🚀 Installation & Setup
# Clone the repository
git clone https://github.com/Niravvasani12/QR-Gen.git

# Navigate into project
cd QR-Gen

# Install dependencies
npm install

# Start development server
npm start

App runs on:

http://localhost:3000
🔐 Environment Variables

Create a .env file in the root directory:

REACT_APP_WEB3FORMS_ACCESS_KEY=your_access_key_here

This is required for the contact form to work.

🏗️ Production Build
npm run build

Creates optimized production files in the build/ folder.

🌍 Deployment

Deployed on Vercel with automatic GitHub integration.
